# Mobile Digital Business Card - Nadee Senanayake

A sleek, premium, mobile-first digital business card designed with a modern Frosted Dark Glassmorphism aesthetic. It seamlessly integrates direct contact channels and aligns with the brand identity of `nadeesenanayake.com`.

## 🌟 Key Features
- **Modern Glassmorphism UI:** Frosted dark glass container styling with soft background ambient gradients.
- **Brand Consistency:** Designed around a rich Burgundy (`#6B1D2F`), Cream/Off-White, and Dark Slate palette.
- **One-Tap Quick Actions:**
  - Direct WhatsApp connection with pre-filled message support.
  - One-click Instagram profile redirection.
  - Direct telephone call trigger.
- **Service Highlights:** Interactive visual cards for Business Strategy, Brand Growth, Consulting, and Partnership Support.

## 🛠️ Built With
- HTML5
- Tailwind CSS (Utility-first styling & layout composition)
- SVG Icons (Inline for optimum performance and clean rendering)
